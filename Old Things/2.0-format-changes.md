# 2.0 格式变更

- 临时格式从 `temp.something[layer]` 改为 `temp[layer].something`，以保持一致性
- 挑战现在保存为一个对象，其中包含每个位置的完成次数。（这将导致存档失效。）
- 挑战和升级中的 `effectDisplay` 不再接受参数，购买项中的 `effect` 也是如此
- 购买项成本可以接受一个参数来表示购买数量，但需要在未提供参数时也能正常工作（应计算下一次购买的成本）。
- 点数生成现在在主游戏循环中进行（不在层更新函数中），由 [game.js](js/game.js) 中的 `canGenPoints` 启用。
- 将 `fullLayerReset` 改为 `layerDataReset`，它接受一个要保留的值名称数组。

此外，许多名称已更改，主要是扩展了缩写：

所有出现以下内容的地方：
- chall -> challenge
- unl -> unlocked
- upg -> upgrade（CSS 除外）
- amt -> amount
- desc -> description
- resCeil -> roundUpCost
- order -> unlockOrder
- incr_order -> increaseUnlockOrder

挑战：
- desc -> challengeDescription
- reward -> rewardDescription
- effect -> rewardEffect
- effectDisplay -> rewardDisplay
- active -> challengeActive
