# 树与树的定制

如果你希望在左侧标签页中拥有超越标准树形结构的内容，可以在tree.js中实现。你可以更改树的布局，包括创建非图层节点、将其改为树以外的形式，或完全隐藏左侧标签页。这也引入了“树”组件，可在你的图层中使用。

## layoutInfo
最重要的部分是layoutInfo，包含：
- startTab：游戏开始时右侧默认显示的标签页ID。
- startNavTab：游戏开始时左侧默认显示的标签页ID。

- showTree：若为true，则游戏开始时显示树标签页。（另一个标签页将占满整个页面）
- treeLayout：如果存在，将覆盖树布局，并按你的描述放置节点（在下一节中说明）。

此外，如果你希望主布局不是树形结构，可以编辑tree.js底部的“tree-tab”图层，像修改普通图层的标签页一样修改它。你甚至可以在左侧标签页之间切换，使用showNavTab(layer)让该图层出现在左侧。

## 树

树组件定义为数组的数组，包含要在树中显示的图层或节点的名称。它们与主树中的图层/节点工作方式相同（但如果存在重复项，节点之间的分支将仅作用于第一个节点）。

以下是一个树的示例：
```js
[["p"],
 ["left", "blank", "right", "blank"]
 ["a", "b", "blank", "c", "weirdButton"]]
```

## 节点

节点是非图层按钮，可放置在树中。它们的定义方式与图层类似，但使用addNode而非addLayer。

功能：

- color：**可选**，节点的颜色。（带#的十六进制格式字符串）

- symbol：**可选**，按钮上的文本（默认将ID首字母大写）

- canClick()：返回true表示玩家可以点击该节点。

- onClick()：点击节点时调用的函数。

- layerShown()：**可选**，返回布尔值的函数，决定该节点是否应可见。它也可以返回“ghost”，这将隐藏图层，但其节点仍会占据树中的空间。

- branches：**可选**，图层/节点ID的数组。在树上，将从此节点到列表中的所有节点绘制一条连线。或者，数组中的条目可以是包含ID和颜色值的两元素数组。颜色值可以是十六进制颜色代码字符串，或1-3的数字（受主题影响的颜色）。

- nodeStyle：**可选**，CSS对象，键为CSS属性，用于设置树上节点的样式。

- tooltip() / tooltipLocked()：**可选**，返回文本的函数，分别用于图层解锁或锁定时节点的提示文本。默认情况下，提示行为与原始声望树相同。

- row：**可选**，此节点在默认树中出现的行。

- position：**可选**，决定图层在默认树中其行内的水平位置。默认情况下，使用ID，图层/节点按字母顺序排序。
