# 子标签与微标签

子标签是标签页中独立的区块，你可以通过点击标签页顶部的选项来查看它们。微标签是功能类似但更小的区域。你也可以在子标签/微标签中嵌入层级。

子标签通过如下所示的标签格式来定义，其中 `tabFormat` 的每个元素都被赋予该子标签的名称：

```js
tabFormat: {
    "主标签": {
        content: [标签格式内容],
        *子标签特性*
    },
    "其他标签": {
        content: [标签格式内容],
        *子标签特性*
    },
    等等
}
```

微标签的定义方式类似，并使用相同的特性，但它们在“microtabs”特性中定义。每个条目是一组标签，这些标签将显示在一个微标签组件中。第一组“stuff”有2个标签，第二组“otherStuff”则没有。

```js
microtabs: {
    stuff: {
        first: {
            content: [标签格式内容],
            *子标签特性*
        },
        second: {
            content: [标签格式内容],
            *子标签特性*
        }
    },
    otherStuff: {
        // 这里可以有另一组微标签
    }
}
```

普通子标签和微标签子标签都使用相同的特性：

# 特性：

- content: 子标签的标签布局代码，格式见[标签布局格式](custom-tab-layouts.md)。

- style: **可选**。切换到此子标签时，以“CSS对象”的形式将CSS应用于整个子标签，其中键为CSS属性，值为这些属性的值（均为字符串）。

- buttonStyle: **可选**。一个CSS对象，影响该子标签按钮的外观。

- unlocked(): **可选**。一个函数，用于确定此子标签的按钮是否应可见。默认情况下，子标签始终是解锁的。在此函数中不能使用“this”关键字。

- shouldNotify()/prestigeNotify(): **可选**，如果为true，标签按钮将被高亮显示，以通知玩家此处有内容。

- glowColor: **可选**，指定子标签发光的颜色。如果此子标签导致主层级节点发光（且原本不会发光），节点也会以该颜色发光。嵌入层级不会覆盖此设置。

- embedLayer: **重要**，另一个层级的id。如果设置了此项，它将覆盖“content”、“style”和“shouldNotify”，而是在子标签中显示整个层级。
