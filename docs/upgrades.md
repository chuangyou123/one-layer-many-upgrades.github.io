# 升级

处理升级及其效果实现的有用函数：

- hasUpgrade(layer, id)：判断玩家是否拥有该升级
- upgradeEffect(layer, id)：返回升级的当前效果（如果有）
- buyUpgrade(layer, id)：直接购买升级（如果可负担）

提示：基础点数获取在 [mod.js](/js/mod.js) 的 "getPointGen" 函数中计算。

升级以以下格式存储：

```js
upgrades: {
    11: {
        description: "Blah",
        cost: new Decimal(100),
        etc
    },
    etc
}
```

通常，升级的 id 中第一位数字代表行，第二位数字代表列。

单个升级可以具有以下特性：

- title：**可选**。以较大字体显示在顶部。也可以是返回更新文本的函数。可以使用基本 HTML。

- description：升级效果的描述。*您还需要在应用效果的地方实现该效果。* 也可以是返回更新文本的函数。可以使用基本 HTML。

- effect()：**可选**。计算并返回升级当前加成值的函数。可以返回一个值或包含多个值的对象。

- effectDisplay()：**可选**。返回升级当前效果格式化显示的函数。默认不显示任何内容。可以使用基本 HTML。

- fullDisplay()：**覆盖**。覆盖其他显示和描述，允许您设置升级的完整文本。可以使用基本 HTML。

- cost：**某种程度上可选**。升级费用的 Decimal 值。默认情况下，升级消耗该层的主要声望货币。

- unlocked()：**可选**。返回布尔值的函数，用于判断升级是否可见。默认为已解锁。

- onPurchase()：**可选**。购买升级时将调用此函数。适用于诸如“使该层表现得像是先被解锁”之类的升级。

- style：**可选**。以对象形式向此升级应用 CSS，其中键为 CSS 属性，值为这些属性的值（均为字符串）。

- tooltip：**可选**。为此升级添加工具提示，悬停时显示。可以使用基本 HTML。默认为无工具提示。如果返回空值，也会禁用工具提示。

- layer：**自动分配**。与该层名称相同，因此您可以执行 `player[this.layer].points` 或类似操作。

- id：**自动分配**。升级存储所用的“键”，便于访问。示例中升级的 id 为 11。

默认情况下，升级使用该层的主要声望货币。您可以包含以下内容来更改它们（但需要是 Decimal）：

- currencyDisplayName：**可选**。升级货币的显示名称。

- currencyInternalName：**可选**。该货币的内部名称。

- currencyLayer：**可选**。该货币存储所在层的内部名称。如果不在层中（如点数），则省略。如果未直接存储在层中，请改用下一个特性。

- currencyLocation：**可选**。如果您的货币存储在层内的某个对象中（例如可购买物的数量），您可以通过此方式访问。这是一个返回 "player" 中包含该值的对象的函数（如 `player[this.layer].buyables`）

如果您想进行更复杂的操作，例如需要两种货币的升级，或有额外要求，您可以使用以下内容覆盖购买系统。（如果您不使用 "cost"，则需要使用 fullDisplay）

- canAfford()：**覆盖**，判断您是否能够购买升级的函数。（如果您同时有 cost，它将同时检查 cost 和此函数）

- pay()：**覆盖**，购买升级时减少您货币的函数。



- branches：**可选**，主要用于升级树。一个升级 id 数组。从该升级到列表中的所有升级将出现一条连线。或者，数组中的条目可以是一个由升级 id 和颜色值组成的双元素数组。颜色值可以是包含十六进制颜色代码的字符串，也可以是 1-3 的数字（受主题影响的颜色）。数组中的第三个元素可选地指定线宽。
