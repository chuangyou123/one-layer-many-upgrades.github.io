# 其他事项

## CSS
为你的游戏赋予独特风格的一个好方法是自定义其外观。修改CSS文件有助于你在全局层面实现这一点。CSS被拆分成多个文件，以便更容易找到与你相关的内容。
CSS小贴士：每个组件都会自动获得一个与其图层ID同名的CSS类。你可以利用这一点来专门为单个图层应用样式！你还可以组合类，例如`.p.achievement`或`.c.locked`，以更改特定图层中的特定内容。

## Temp
temp/tmp（两者皆可）是一种数据结构，它是图层的副本（包含你定义的所有图层数据及默认内容），但它会将大多数函数替换为调用这些函数的结果。例如，如果图层p的baseAmount基于点数，那么layers.p.baseAmount是一个返回player.points的函数。玩家当前有54点，因此temp.p.baseAmount为54（以Decimal形式表示）。你可以使用temp来提升性能。
