# 层特性

这是一个更全面的列表，列出了可以添加到层中的既有特性。如果你希望你的层拥有其他功能或数值，也可以自由添加更多。不过，这些特性具有特殊功能。

你可以通过使用函数来使几乎任何值动态化，包括所有显示字符串和样式/颜色特性。

## 层定义特性

- layer：**自动分配**。它与该层的名称相同，因此你可以使用 `player[this.layer].points` 或类似方式访问保存的值。这使得将代码复制到新层更容易。它也会分配给所有升级、可购买物等。

- name：**可选**。用于重置确认（以及默认信息框标题）。如果缺失，则使用层的 id。

- startData()：一个返回该层默认存档数据的函数。将你拥有的任何变量添加到其中。确保使用 `Decimal` 值而不是普通数字。

    标准值：
        - 必需：
            - unlocked：一个布尔值，决定该层是否已解锁
            - points：一个 Decimal，该层的主要货币
        - 可选：
            - total：一个 Decimal，追踪主要声望货币的总量。始终被追踪，但只有你在此添加时才会显示。
            - best：一个 Decimal，追踪主要声望货币的最高数量。始终被追踪，但只有你在此添加时才会显示。
            - unlockOrder：用于跟踪在此层之前解锁的相关层。
            - resetTime：一个数字，表示自该层上次声望重置（或被其他层重置）以来的时间。

- color：与该层关联的颜色，用于许多地方。（十六进制格式的字符串，带 #）

- row：该层的行，从 0 开始。这影响节点在标准树上的位置，以及哪些重置会影响该层。

    使用 "side" 而不是数字将使该层作为较小的节点出现在侧面（适用于成就和统计）。侧层不受重置影响，除非你为它们添加 doReset。

- displayRow：**覆盖**。更改层节点的显示位置，而不改变其在重置顺序中的位置。

- resource：通过重置此层获得的主要货币名称。

- effect()：**可选**。一个计算并返回主要货币固有加成当前值的函数。可以返回一个值或包含多个值的对象。*你还必须在应用效果的地方实现它。*

- effectDescription：**可选**。一个返回此效果描述的函数。如果文本保持不变，也可以直接是字符串。

- layerShown()：**可选**，一个返回布尔值的函数，决定该层的节点是否应在树上可见。它也可以返回 "ghost"，这将隐藏该层，但其节点仍会占据树上的空间。
    默认为 true。

- hotkeys：**可选**。一个包含与该层关联的任何快捷键信息的数组：

    ```js
    hotkeys: [
        {
            key: "p", // 快捷键按钮是什么。如果与 shift 组合使用则用大写，或使用 "ctrl+x" 表示按住 ctrl。
            description: "p: 重置你的点数以获得声望点数", // 在游戏的“如何游玩”标签页中显示的快捷键描述
            onPress() { if (player.p.unlocked) doReset("p") },
            unlocked() {return hasMilestone('p', 3)} // 决定你是否可以使用该快捷键，可选
        }
    ]
    ```

- style：**可选**。一个“CSS 对象”，其中键是 CSS 属性，包含任何应影响该层整个标签页的 CSS。

- tabFormat：**可选**。如果你想向标签页添加额外内容或更改布局，请使用此项。[更多信息请参见此处。](custom-tab-layouts.md)

- midsection：**可选**，`tabFormat` 的替代方案，插入到标准标签页布局中的里程碑和可购买物之间。（不能使用子标签页）

## 主要特性（均为可选）

- upgrades：一组一次性购买，可以具有独特的升级条件、货币成本和加成。[更多信息请参见此处。](upgrades.md)

- milestones：达到某个资源的特定阈值后获得的加成列表。常用于自动化/生活质量改进。[更多信息请参见此处。](milestones.md)

- challenges：玩家可以进入挑战，使游戏更难。如果他们达到目标并击败挑战，将获得加成。[更多信息请参见此处。](challenges.md)

- buyables：实际上是可多次购买且可选重置的升级。用途广泛。[更多信息请参见此处。](buyables.md)

- clickables：极其通用和泛化的按钮，只能在某些时候点击。[更多信息请参见此处。](clickables.md)

- microtabs：一个功能类似于一组子标签页的区域，顶部有按钮更改其中的内容。（高级）[更多信息请参见此处。](subtabs-and-microtabs.md)

- bars：将某些信息显示为进度条、仪表或类似形式。高度可定制，也可以是垂直的。[更多信息请参见此处。](bars.md)

- achievements：类似于里程碑，但显示风格不同且有一些其他差异。更多功能将在未来推出！[更多信息请参见此处。](achievements.md)

- achievementPopups、milestonePopups：**可选**，如果为 false，则获得成就/里程碑时禁用弹出消息。默认为 true。

- infoboxes：在可显示或隐藏的框中显示一些文本。[更多信息请参见此处。](infoboxes.md)

- grid：一个按钮网格，行为相同，但各自拥有自己的数据。[更多信息请参见此处。](grids.md)

## 声望公式特性

- type：**可选**。决定你使用哪种声望公式。默认为 "none"。

    - "normal"：你获得的货币数量与其当前数量无关（如声望）。加成前的公式基于 `baseResource^exponent`
    - "static"：成本取决于你重置后的总量。加成前的公式基于 `base^(x^exponent)`
    - "custom"：你可以自己定义一切，从计算到按钮上的文本。（请参见底部更多信息）
    - "none"：该层不进行声望重置，因此不需要本节中的任何其他特性。

- baseResource：决定重置时获得多少主要货币的资源的名称。

- baseAmount()：一个获取基础资源当前值的函数。

- requires：一个 Decimal，获得 1 个声望货币所需的基础数量。也是解锁该层所需的数量。你也可以将其设为函数，以便在另一个层先解锁时使其更难（基于 unlockOrder）。

- exponent：如上所述使用。

- base：**有时必需**。对于 "static" 层是必需的，如上所述使用。如果缺失，默认为 2。必须大于 1。

- roundUpCost：**可选**。一个布尔值，如果资源成本需要向上取整则为 true。（如果基础资源是“静态”货币则使用。）

- gainMult()、gainExp()：**可选**。对于普通层，这些函数计算来自升级和加成等的资源获取的乘数和指数。在此处接入大多数加成。
    对于静态层，它们分别乘以和开方资源成本。（因此要获得加成，你需要使 gainMult 更小，gainExp 更大。）

- directMult()：**可选**。直接乘以资源获取，在指数和软上限之后。对于静态层，实际上乘以资源获取而不是降低成本。

- softcap、softcapPower：**可选**。对于普通层，超过 [softcap] 点的获取量被取 [softcapPower] 次方。
    softcap 默认为 e1e7，power 默认为 0.5。

## 其他声望相关特性

- canBuyMax()：**有时必需**。对于静态层是必需的，用于确定是否允许购买最大值的函数。

- onPrestige(gain)：**可选**。当该层进行声望重置时触发的函数，就在你获得货币之前。可用于在声望时获得次要资源，或重新计算事物等。

- resetDescription：**可选**。用其他内容替换声望按钮上的“重置以获取”。

- prestigeButtonText()：**有时必需**。用于使声望按钮包含的文本完全自定义。仅对自定义层是必需的，但所有类型都可以使用。

- passiveGeneration()：**可选**，返回一个普通数字。你每秒自动生成你的获取量乘以该数字（如果缺失则无效）。
        这对于自动化普通层很好。

- autoPrestige()：**可选**，返回一个布尔值，如果为 true，该层将始终在可能时自动进行声望重置。
        这对于自动化静态层很好。

## 树/节点特性

- symbol：**可选**。显示在该层节点上的文本。默认为层 id 并将首字母大写。

- image：**覆盖**。节点上显示的图片的 URL（本地或全局）。（覆盖 symbol）

- position：**可选**。决定该层在标准树中其行内的水平位置。默认使用层 id，层按字母顺序排序。

- branches：**可选**。一个层/节点 id 数组。在树上，将出现一条从该层到列表中所有层的线。或者，数组中的条目可以是一个由层 id 和颜色值组成的 2 元素数组。颜色值可以是十六进制颜色代码的字符串，或 1-3 的数字（受主题影响的颜色）。数组中的第三个元素可选地指定线宽。

- nodeStyle：**可选**。一个 CSS 对象，其中键是 CSS 属性，用于样式化该层在树上的节点。

- tooltip() / tooltipLocked()：**可选**。返回文本的函数，分别是该层解锁或锁定时节点的工具提示。默认情况下，工具提示行为与原始声望树相同。
    如果值为 ""，则禁用工具提示。

- marked：**可选**。在节点角落添加标记。如果为 "true" 则为星形，但也可以是图片 URL。

## 其他特性

- doReset(resettingLayer)：**可选**。当行号大于或等于此层的层进行重置时触发。默认行为是重置该行上的所有内容，但仅当由更高行的层触发时。`doReset` 总是为侧层调用，但对于这些层，默认行为是不重置任何内容。
                
    如果你想保留某些内容，请根据 `resettingLayer`、`milestones` 等确定要保留的内容，然后调用 `layerDataReset(layer, keep)`，其中 `layer` 是此层，`keep` 是要保留的内容名称数组。它可以包括 "points"、"best"、"total"（用于此层的声望货币）、"upgrades"、任何唯一变量如 "generatorPower" 等。如果你想只保留特定的升级或类似内容，请将它们保存在单独的变量中，然后调用 `layerDataReset`，再将 `player[this.layer].upgrades` 设置为保存的升级。

- update(diff)：**可选**。此函数在每个游戏刻调用。用于任何被动资源生产或基于时间的操作。`diff` 是自上次刻以来的时间。

- autoUpgrade：**可选**，一个布尔值，如果为 true，游戏将每刻尝试购买此层的升级。默认为 false。

- automate()：**可选**。此函数在每个游戏刻调用，在生产之后。用于激活其他方式不支持的自动化操作。

- resetsNothing：**可选**。如果该层在声望时不应触发任何重置，则返回 true。

- increaseUnlockOrder：**可选**。一个层 id 数组。当此层首次解锁时，此列表中任何尚未解锁的层的 `unlockOrder` 值会增加。这可用于使它们更难解锁。

- shouldNotify：**可选**。一个函数，如果该层应在树中高亮显示则返回 true。无论你是否拥有此函数，如果你可以购买升级，该层将自动高亮显示。

- glowColor：**可选**。如果该层应通知，则高亮显示的颜色。默认为红色。如果你想要几种不同的通知类型，可以使用此功能！

- componentStyles：**可选**。一个包含一组返回 CSS 对象的函数的对象。每个函数将应用于该层上具有其 id 类型的任何组件。示例：

```js
componentStyles: {
    "challenge"() { return {'height': '200px'} },
    "prestige-button"() { return {'color': '#AA66AA'} }
}
```

- leftTab：**可选**，如果为 true，该层将使用左侧标签页而不是右侧标签页。

- previousTab：**可选**，一个层的 id。如果一个层有 previousTab，该层将始终有一个返回箭头，按下此层上的返回箭头将带你到具有此 id 的层。

- deactivated：**可选**，如果为 true，hasUpgrade、hasChallenge、hasAchievement 和 hasMilestone 将对该层中的内容返回 false，并且你将无法购买或点击内容，或在该层获得成就/里程碑。你将需要自行禁用可购买物的效果、固有层效果，以及可能其他内容。

## 自定义声望类型  
（以下所有内容也可用于其他声望类型）

- getResetGain()：**主要用于自定义声望类型**。返回如果你现在重置应获得多少点数。你可以调用 `getResetGain(this.layer, useType = "static")` 或类似方式来计算你在另一种声望类型下的获取量（前提是你拥有该层中所有必需的特性）。

- getNextAt(canMax=false)：**主要用于自定义声望类型**。返回你需要多少基础货币才能达到下一点。`canMax` 是一个可选变量，用于类似静态的层，以区分是在寻找你可以重置的第一个点，还是任何获取的要求（同时支持两者更好）。你也可以调用 `getNextAt(this.layer, canMax=false, useType = "static")` 或类似方式来计算你在另一种声望类型下的下一个点（前提是你拥有该层中所有必需的特性）。

- canReset()：**主要用于自定义声望类型**。仅当你拥有在此进行声望重置所需资源时返回 true。

- prestigeNotify()：**主要用于自定义声望类型**，如果该层应被微妙地高亮以指示你可以进行有意义的声望重置，则返回 true。
