# 里程碑

当玩家达成特定目标时，将获得里程碑奖励，并带来某些好处。里程碑的格式如下：

```js
milestones: {
    0: {
        requirementDescription: "123 个华夫饼",
        effectDescription: "等等",
        done() { return player.w.points.gte(123) }
    }
    等等
}
```

你可以使用 `hasMilestone(layer, id)` 来判断玩家是否已获得某个里程碑。

里程碑特性：

- requirementDescription：描述解锁此里程碑所需条件的字符串。建议使用“总计”形式。也可以是返回更新文本的函数。支持基本 HTML。

- effectDescription：描述拥有此里程碑所获奖励的字符串。*你需要在其他地方实现该奖励。* 也可以是返回更新文本的函数。支持基本 HTML。

- done()：返回布尔值的函数，用于判断是否应授予里程碑。

- onComplete() - **可选**。当里程碑完成时将调用此函数。

- toggles：**可选**。在里程碑解锁时创建显示在其上的切换按钮。这些切换按钮可以切换某个层中的布尔值。它被定义为成对项目的数组，每对对应一个切换按钮。第一个是存储被切换值的层的内部名称，第二个是要切换的变量的内部名称。（例如 [["b", "auto"], ["g", "auto"]）

   **提示：** 如果里程碑被锁定，切换按钮不会被取消设置！在这种情况下，你还应检查玩家是否拥有该里程碑。

- style：**可选**。以对象形式向此里程碑应用 CSS，其中键为 CSS 属性，值为这些属性的值（均为字符串）。

- unlocked()：**可选**。返回布尔值的函数，用于判断是否应显示里程碑。如果省略，则始终显示。

- tooltip：**可选**。为此里程碑添加工具提示，在悬停时显示。支持基本 HTML。默认为无工具提示。如果返回空值，也会禁用工具提示。

- layer：**自动分配**。与层名称相同，因此你可以使用 `player[this.layer].points` 或类似操作。

- id：**自动分配**。里程碑存储时所用的“键”，便于访问。示例中里程碑的 id 为 0。

通过在层中添加 `milestonePopups: false` 可禁用里程碑弹窗。
