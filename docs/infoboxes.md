# 信息框

信息框适合展示“背景设定”或故事元素，也适合解释复杂的内容。

在默认的标签页布局中，第一个信息框会显示在标签页的最顶部。

信息框的定义方式与其他大型功能相同：

```js
infoboxes: {
    lore: {
        title: "foo",
        body() { return "bar" },
        etc
    },
    etc
}
```

功能特性：

- title：显示在主框上方的文本。可以是函数以实现动态内容，并支持基础HTML。

- body：显示在框内的文本。可以是函数以实现动态内容，并支持基础HTML。

- style、titleStyle、bodyStyle：**可选**。以对象形式为信息框、标题按钮或信息框主体应用CSS，其中键为CSS属性，值为这些属性的值（均为字符串）。

- unlocked()：**可选**。返回布尔值的函数，用于判断信息框是否可见。默认为已解锁。

- layer：**自动分配**。其值与此层的名称相同，因此你可以使用 `player[this.layer].points` 或类似操作。

- id：**自动分配**。这是该信息框存储时所用的“键”，便于访问。示例中信息框的id为“lore”。
