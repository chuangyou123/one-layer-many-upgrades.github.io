# 挑战

挑战可以拥有完全可自定义的胜利条件。用于处理挑战及实现其效果的有用函数：

- inChallenge(layer, id)：判断玩家当前是否处于某个挑战中（或同一层中可视为该挑战的其他挑战）。
- hasChallenge(layer, id)：判断玩家是否已完成该挑战。
- challengeCompletions(layer, id)：获取玩家完成该挑战的次数。
- maxedChallenge(layer, id)：判断玩家是否已达到最大完成次数。
- challengeEffect(layer, id)：返回挑战当前的效果（如果有）。

挑战以以下格式存储：

```js
challenges: {
    11: {
        name: "哎哟",
        challengeDescription: "疼疼疼的描述",
        canComplete: function() {return player.points.gte(100)},
        etc
    },
    etc
}
```

通常，每个挑战的 id 中第一位数字代表行，第二位数字代表列。

单个挑战可以包含以下特性：

- name：挑战的名称，可以是字符串或函数。可以使用基础 HTML。

- challengeDescription：描述该挑战为何构成挑战的说明。*你需要在其他地方实现这些效果。* 也可以是返回动态更新文本的函数。可以使用基础 HTML。

- goalDescription：描述挑战胜利条件的说明。也可以是返回动态更新文本的函数。
    可以使用基础 HTML。（使用旧目标系统时可省略）

- canComplete()：一个函数，当满足挑战的胜利条件时返回 true。返回数字将允许批量完成挑战。
    （使用旧目标系统时可省略）

- rewardDescription：描述奖励效果的说明。*你还需要在应用奖励效果的地方实现该效果。* 也可以是返回动态更新文本的函数。可以使用基础 HTML。

- rewardEffect()：**可选**。一个函数，用于计算并返回奖励带来的任何加成的当前值。可以返回一个值或包含多个值的对象。可以使用基础 HTML。

- rewardDisplay()：**可选**。一个函数，返回奖励当前效果的格式化显示。默认行为是仅以适当格式显示数字。

- fullDisplay()：**覆盖**。覆盖其他显示和描述，允许你设置挑战的完整文本。可以使用基础 HTML。

- unlocked()：**可选**。一个返回布尔值的函数，用于判断挑战是否可见。默认为已解锁。

- onComplete() - **可选**。当挑战在之前未完成的状态下被完成时，将调用此函数。

- onEnter() - **可选**。当进入挑战时将调用此函数。

- onExit() - **可选**。当以任何方式退出挑战时将调用此函数。

- countsAs：**可选**。如果某个挑战结合了本层其他挑战的效果，可以使用此特性。它是一个挑战 id 数组。玩家在当前挑战中时，实际上也处于所有这些挑战中。

- completionLimit：**可选**。你可以完成此挑战的次数上限。默认为 1 次完成。

- style：**可选**。以对象形式向该挑战应用 CSS，其中键为 CSS 属性，值为这些属性的值（均为字符串）。

- marked：**可选**。在挑战角落添加标记。如果为 "true" 则显示为星号，但也可以是图片 URL。默认情况下，如果挑战有多次完成，则在达到最大完成次数时显示星号。

- layer：**自动分配**。与本层名称相同，因此你可以使用 player[this.layer].points 等操作。

- id：**自动分配**。即挑战存储时所用的"键"，便于访问。示例中挑战的 id 为 11。



旧目标系统使用以下特性：

- goal：**已弃用**，一个 Decimal 值，表示通关挑战所需的货币数量。默认情况下，目标为基础点数。如果其值会变化，goal 也可以是函数。

- currencyDisplayName：**已弃用**。目标所用货币的显示名称。

- currencyInternalName：**已弃用**。该货币的内部名称。

- currencyLayer：**已弃用**。该货币存储所在层的内部名称。如果不在层中，则省略。如果不是直接存储在层中，则改用下一个特性。

- currencyLocation()：**已弃用**。如果你的货币存储在层内某个对象中（例如可购买物的数量），可以通过此方式访问。这是一个函数，返回 "player" 中包含该值的对象（如 `player[this.layer].buyables`）。
