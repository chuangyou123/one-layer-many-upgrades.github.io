# 制作模组

本指南假设您已经完成了[入门指南](getting-started.md)。它将带您了解使用TMT创建模组的基础知识。让我们开始吧！

## 设置模组信息

打开mod.js。这里定义的是模组整体而非特定层级的属性。目前，在modInfo中，您可以设置模组名称、作者名称，以及点数名称——这会改变游戏对基础点数的称呼（但在代码中仍以`player.points`引用）。**请务必同时设置模组ID**。

一个建议：测试模组时，请在游戏设置中关闭离线进度，并且在不使用时不要让游戏保持运行。否则，您可能会因这些额外时间而无意中在游戏中设置过长的等待时间，影响平衡。

## 创建层级

现在进入正题！打开layers.js。这里已经有一个基础层级（虽然其中包含一些冗余内容）。让我们看看它在做什么……

最重要的事情在第一行，即`addLayer("p", {`。这就是创建新层级的方式。这里的"p"成为层级ID，在整个TMT中用于引用该层级。您可以更改ID，但需要同时替换教程代码中所有"p"的实例。

层级本质上是一个包含许多不同属性的大对象，您可以设置这些属性来创建功能。为了有趣的定制，您可以更改以下几项：
- name：层级的名称！
- color：设置该层级许多相关内容的颜色。（可以是十六进制颜色代码或颜色名称）
- symbol：显示在该层级节点上的文本。
- resource：该层级主要货币的名称。

刷新页面即可看到您新定制的层级！暂时可以忽略层级中的其他功能。其中大部分涉及计算您获得多少声望点。现在，让我们制作一个升级！

## 升级

升级是TMT中几个主要功能之一，它们大多以相同方式运作。适用于升级的大部分内容也适用于里程碑、可购买项等。要向层级添加升级，请在最后一个功能后添加逗号，然后输入：

```js
    upgrades: {

    },
```

"upgrades"是一个对象，其中包含每个升级的对象。每个升级都有一个与其位置对应的ID。升级"12"将显示为第一行第二个升级。

基于此，让我们制作第一个升级！在"upgrades"后的括号之间插入这一行：

```js
        11: {

        },
```

刷新页面，升级将出现在层级的标签页中！但它目前只是空白的。我们需要填写其功能，这与给层级添加功能类似。以下是所需的功能：

```js
    title: "随意填写你想要的标题！",
    description: "使点数获取翻倍。",
    cost: new Decimal(1),
```

刷新页面，升级将完整显示！但购买后不会有任何效果！要实现加成，我们需要前往计算该数值的地方。在本例中，点数获取在mod.js的getPointGen中计算，所以我们去那里看看。

现在该解释Decimal了。Decimal是一种特殊方式，用于处理超出常规Javascript限制的数字。它们的处理方式非常不同。要执行任何运算，不能使用x = x + y，而必须使用x = x.add(y)。x必须是Decimal，而y可以是Decimal或Number（常规Javascript数字）。更详细的描述见[!general-info.md](/docs/!general-info.md)

掌握了这些知识，我们需要做的是检查玩家是否拥有该升级，如果有则提升点数获取。我们可以通过在gain定义和返回之间插入这一行来实现：
```js
if (hasUpgrade('p', 11)) gain = gain.times(2)
```

再次刷新页面，应该就能生效了！您现在每秒获得2点！

## 进阶升级

既然您知道如何制作简单升级了，让我们制作一个更有趣的升级，其效果会根据您的声望点进行缩放！

复制粘贴通常是最简单的操作方式，所以复制升级11并粘贴在其后。将11替换为12，按需更改名称和描述，并将成本提高到2。现在，让我们添加一个效果。effect是一个计算升级加成的函数，而effectDisplay让您可以显示该效果。

```js
    effect() {
        return player[this.layer].points.add(1).pow(0.5)
    },
    effectDisplay() { return format(upgradeEffect(this.layer, this.id))+"x" }, // 为效果添加格式化
```

this.layer和this.id会自动设置为升级所在的层级以及升级的ID（本例中为"12"）。使用它们可以大大简化代码复用。您还可以看到player[this.layer].points获取该层级的声望货币数量。

现在，在mod.js中，在您添加的最后一行下方，您可以通过以下方式应用效果：

```js
    if (hasUpgrade('p', 12)) gain = gain.times(upgradeEffect('p', 12))
```

刷新页面看看效果是否生效！现在，最后一个升级，让我们让点数提升声望点获取！复制上一个升级，将编号改为13。更改标题和名称，将成本设为5。（这个模组被设计为快节奏且易于测试）。我们可以复用effectDisplay，所以只需更改effect：

```js
    effect() {
        return player.points.add(1).pow(0.15)
    },
```

要实现此效果，我们修改gainMult，它返回该层级声望获取的倍率。

```js
    gainMult() {
        let mult = new Decimal(1)
        if (hasUpgrade('p', 13)) mult = mult.times(upgradeEffect('p', 13))
        return mult
    },
```

刷新页面，看看您的新升级！下次：创建新层级……
